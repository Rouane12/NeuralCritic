# Neural Critic Improvement Checklist

This file is a durable growth backlog for Neural Critic. It records owner-provided priorities that should remain available across future chats and work sessions.

## Operating rules

- Treat this as a rolling improvement checklist, not proof that every item is currently unimplemented.
- Before starting an item, verify the current live state in GitHub, Supabase, production, analytics, and relevant project sources so completed or partially completed work is not repeated.
- Extend established Neural Critic architecture and workflows rather than replacing them without a strong reason.
- Mark progress only after the relevant code, editorial, analytics, commerce, publishing, or production state has been verified.
- Keep this list durable. Update statuses or notes as work advances; do not silently remove owner priorities.

## Checklist

1. Publish more content (aim for 3–5 articles per week).
2. Make titles specific and searchable.
3. Improve meta descriptions so more people click.
4. Add internal links between related articles.
5. Create “What to Play” lists and evergreen guides.
6. Add a clean “Where to Buy” box on reviews and buying guides.
7. Join Amazon Associates and start using affiliate links.
8. Post regularly on Reddit (value first, then links).
9. Share articles on X/Twitter and Bluesky.
10. Make short video clips from articles (TikTok, Shorts, Reels).
11. Promote the newsletter more.
12. Make the scoreboard useful so people come back.
13. Keep the site fast on mobile.
14. Soften the analytics popup.
15. Add an About page and author info.
16. Track traffic with Google Analytics and Search Console.
17. Later: create buyer guides and apply to more affiliate programs.

## Planning note

These items should be considered alongside the current Neural Critic growth priorities: search-led editorial growth, evergreen game clusters, returning-reader growth, newsletter acquisition, internal recirculation, monetization readiness, and editorial velocity without sacrificing QA. When choosing the next task, prefer the highest-leverage verified gap rather than simply working down the list mechanically.
